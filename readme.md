# AI-Powered Football Match Outcome Predictor

A web-based application that fetches historical and upcoming football match data, stores it in a local SQLite database, predicts 1X2 match outcomes using Machine Learning (Scikit-learn), and visualizes team statistics in an interactive Streamlit dashboard.

## Tech Stack
- **Language:** Python 3
- **UI & Charts:** Streamlit, Plotly
- **Data & ML:** Pandas, NumPy, Scikit-learn
- **Database & API:** SQLite (DBeaver), Requests (Postman)
- **Quality & Traceability:** Git, GitHub Issues, Ruff
